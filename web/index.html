GitHub link and repository instructions

Use a repository link: open the project’s GitHub page, copy the URL from the browser address bar, and paste it above. Use the main repository URL, such as https://github.com/owner/project. Public repositories are supported.

Private repository? Choose ZIP archive and upload a source archive you are authorized to share.

Save generated files to GitHub:

  1. Download the documentation PDF and architecture image below.
  2. Open your repository and choose Add file → Upload files.
  3. Select both downloads, then commit the changes to your branch.

For automatic updates, enable the repository’s .github/workflows/ciao-documentation.yml workflow and grant Actions permission to write repository contents. See the CIAO GitHub repository for the workflow template and setup notes.
