GitHub sync runs in the repository that owns the code. After its workflow is enabled, pushes can regenerate the documentation and architecture files in that repository.

GitHub sync setup

  1. Add CIAO’s .github/workflows/ciao-documentation.yml workflow to the target repository.
  2. Enable GitHub Actions and grant the workflow contents: write permission so it can commit generated files.
  3. Use a runner that can reach Ollama and has the configured model available. A developer’s laptop Ollama is not reachable from GitHub-hosted runners.
  4. Push a normal source change, then check the repository’s Actions page. The workflow writes documentation.pdf and architecture.png by default.

GitHub sync requires the repository owner to install and enable the workflow. The website’s one-time analysis does not turn on synchronization automatically. View the workflow file ↗
